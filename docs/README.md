## 자주 나오는 용어

| 용어 | 쉬운 설명 |
|---|---|
| SSH | 다른 컴퓨터에 원격으로 들어가 명령을 치는 통로. 비밀번호 대신 "키"라는 열쇠 파일로 열 수 있음 |
| GPU 드라이버 | 운영체제가 그래픽카드를 부릴 수 있게 하는 번역기 프로그램 |
| CUDA | NVIDIA GPU로 계산을 시키는 도구 모음. AI 프로그램이 GPU를 쓰려면 필요 |
| llama.cpp | 공개 AI 모델을 일반 서버에서 돌리는 프로그램. 가볍고 설정이 단순해 학습 단계에 적합 |
| GGUF | llama.cpp가 읽는 모델 파일 형식. 모델 하나가 파일 하나(수 GB~수십 GB) |
| vLLM | 여러 사람이 동시에 쓸 때 빠른 AI 서버 프로그램. 서비스 단계에서 검토 |
| systemd 서비스 | 서버가 켜질 때 프로그램을 자동으로 띄워 주는 등록 장치 |
| EPEL | Rocky Linux 기본에 없는 추가 프로그램을 받는 창고(저장소) |
| SELinux | 리눅스의 추가 보안 장치. 프로그램이 허용된 일만 하도록 감시 |
