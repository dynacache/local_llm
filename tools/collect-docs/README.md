# 문서 수집 도구 (사내 AI 비서용)

직원 PC에 흩어진 업무 문서를 NAS의 지정 폴더로 **복사**해 모으는 도구입니다.
원본 파일은 지우거나 옮기지 않습니다. 사진, 동영상, 프로그램 파일은 건드리지 않습니다.

---

## 직원용: 이렇게 실행하세요

1. 팀장이 보내 준 `collect-docs` 폴더를 바탕화면 등 아무 곳에나 둡니다. (4개 파일이 함께 있어야 합니다)
2. 윈도우 탐색기 주소창에 NAS 주소(예: `\\NAS\AI비서`)를 붙여 넣고 NAS 계정으로 한 번 로그인해 둡니다.
3. **`1_미리보기.bat`** 를 더블클릭합니다.
   - 이름을 물어보면 본인 이름을 입력합니다. (엔터만 누르면 윈도우 계정명이 쓰입니다)
   - 복사하지 않고 "무엇을 복사할지" 목록만 만듭니다. 몇 분 걸립니다.
   - 끝나면 요약이 뜨고, 상세 목록은 `내 PC > 사용자 > (내 계정) > AI비서수집로그` 폴더에 저장됩니다.
4. 목록을 열어 보고, 개인적인 파일이 섞여 있으면 그 파일 이름에 들어간 단어를 팀장에게 알려 주세요. 제외 목록에 넣어 드립니다.
5. 괜찮으면 **`2_수집실행.bat`** 를 더블클릭합니다. 실제로 NAS에 복사됩니다.
6. 같은 도구를 나중에 다시 실행해도 됩니다. 이미 복사한 파일은 건너뛰고 새 파일만 복사합니다.

### 어디를 검색하나요
- 바탕화면, 문서, 다운로드 폴더 (OneDrive로 옮겨져 있어도 찾습니다)
- 그 밖의 폴더(예: `D:\업무`)는 팀장이 설정에 추가해야 검색합니다.

### 어떤 파일을 복사하나요
- PDF, 워드(doc/docx), 엑셀(xls/xlsx/xlsm), 파워포인트(ppt/pptx), 한글(hwp/hwpx), 텍스트(txt/csv/rtf/md)
- 200MB보다 큰 파일은 건너뜁니다.

### 복사하지 않는 것
- 파일 이름에 **비밀번호, password, 계좌, 통장, 급여, 연봉, 주민등록, 신분증, 여권, 인감** 이 들어간 파일
  (목록에는 "제외"로만 남고 내용은 NAS로 가지 않습니다)
- 사진, 동영상, 음악, 프로그램, 압축 파일
- 내용이 완전히 같은 중복 파일 (하나만 복사)

### 어디로 복사되나요
```
\\NAS\AI비서\개인\기술지원부\홍길동\
├── 바탕화면\   ← 바탕화면에 있던 구조 그대로
├── 문서\
├── 다운로드\
└── _수집목록.csv   ← 무엇을 언제 복사했는지 기록
```
개인 폴더는 **본인과 관리자만** 볼 수 있도록 NAS 권한을 설정합니다.

### 문제가 생기면
| 화면에 뜨는 말 | 해결 |
|---|---|
| "NAS 폴더에 연결할 수 없습니다" | 탐색기에서 NAS 주소를 열어 로그인한 뒤 다시 실행 |
| "이 시스템에서 스크립트를 실행할 수 없으므로…" | bat 파일로 실행했는지 확인 (ps1을 직접 더블클릭하면 안 됩니다) |
| 창이 바로 닫힘 | bat 파일을 마우스 오른쪽 → "관리자 권한으로 실행"은 **하지 말고**, 그냥 더블클릭. 그래도 닫히면 팀장에게 문의 |
| 한글이 깨져 보임 | 동작에는 문제없습니다. 목록 CSV는 엑셀에서 정상으로 보입니다 |

## 팀장용: 배포 전에 할 일

### 1. NAS 준비
1. Synology에 `AI비서` 공유 폴더를 만들고 그 안에 `개인` 폴더를 만듭니다.
2. `개인` 폴더는 직원 전원에게 **쓰기** 권한을 줍니다. (각자 자기 이름 폴더가 자동으로 생깁니다)
3. 수집이 끝나면 각 이름 폴더를 본인과 관리자만 읽을 수 있게 권한을 조정합니다.

### 2. 설정 파일 고치기 (`collect_config.json`)
메모장으로 열어 아래 항목만 확인하면 됩니다. `_`로 시작하는 항목은 설명이라 지워도 됩니다.

| 항목 | 뜻 | 보통 고치는 값 |
|---|---|---|
| `Destination` | NAS의 `개인` 폴더 주소 | `\\\\NAS이름\\AI비서\\개인` (역슬래시는 두 번씩) |
| `Department` | 부서 이름 | `기술지원부` |
| `UserName` | 비워 두면 실행 때 물어봄 | 직원별 파일을 만들 때만 채움 |
| `ExtraFolders` | 추가 검색 폴더 | `["D:\\\\업무"]` |
| `ExcludeNameKeywords` | 제외할 단어 | 직원 피드백 받아 추가 |
| `FullScan` | PC 전체 검색 | 보통 `false` |

### 3. 나눠 주기
`collect-docs` 폴더(4개 파일)를 통째로 NAS 공유 폴더나 메신저로 전달합니다.
직원은 위 "직원용" 순서대로 미리보기 → 실행 순으로 진행합니다.

### 4. 수집 후 정리
- 각 직원의 `_수집목록.csv`를 엑셀로 열면 "상태" 열로 복사/제외/중복/오류를 한눈에 볼 수 있습니다.
- 개인 폴더에 올라온 문서 중 견적서, 보고서처럼 **회사 자산**인 것은 `AI비서\프로젝트\고객사명\`으로 옮겨야 동료들도 볼 수 있습니다. 반나절 "정리의 날"을 권합니다.
- 이후에는 Synology Drive Client를 각 PC에 설치해 바탕화면과 문서 폴더를 **백업 모드**로 연결하면, 새 문서가 자동으로 NAS에 쌓입니다.

### 5. 관리부에 적용할 때
관리부 PC에는 계좌, 계정 정보가 많으므로 별도 설정 파일을 만들어 `ExcludeNameKeywords`를 크게 늘리고,
먼저 `1_미리보기.bat` 결과를 부서장이 검토한 뒤에만 실행하도록 합니다. 필요하면 수집 자체를 `ExtraFolders`에 지정한 업무 폴더로만 제한합니다.

## 직접 실행할 때 쓸 수 있는 옵션 (참고)
```
powershell -ExecutionPolicy Bypass -File collect_docs.ps1 -DryRun       # 미리보기
powershell -ExecutionPolicy Bypass -File collect_docs.ps1 -FullScan     # 모든 드라이브 검색
powershell -ExecutionPolicy Bypass -File collect_docs.ps1 -NoPrompt     # 질문 없이 진행 (자동화용)
powershell -ExecutionPolicy Bypass -File collect_docs.ps1 -ConfigPath 다른설정.json
```
